# tools/ — 배포 전 검증

## 왜 있나

2026년 8월·9월 점검에서 **같은 종류의 결함이 반복해서** 나왔습니다.

| 회차 | 발견된 가짜 수치 |
|---|---|
| 2026-08-24 | 지역별 예산·인구·채무를 지역명 해시 난수로 생성 |
| 2026-09-03 | 분기별 집행률 `연간값 × 0.22/0.47/0.74` · 분야별 집행률 FNV 해시 ±4%p |
| 2026-09-04 | 4단 자금흐름 `총액 × 0.55/0.25/0.62` · 5년 추이 `총예산 × 0.85/0.88/0.93/0.98` |

새로 생긴 버그가 아닙니다. **시연용으로 만들어진 코드가 한 뭉치로 남아 있었고,
점검할 때마다 그중 일부만 걸린 것**입니다. 사람이 매번 다른 검색어로 찾았기
때문에 매번 다른 것만 나왔습니다.

`total * 0.62`는 얼핏 보면 그냥 산수입니다. 눈으로는 못 잡습니다.
그래서 검사를 고정하고 기계에 맡깁니다.

## 무엇을 검사하나

### `node tools/verify.js` — 정적 검사 (수 초)

1. **조작 계수** — 금액·지표 변수에 리터럴 계수를 곱하는 모든 지점.
   정당한 경우는 `COEF_ALLOW`에 **사유와 함께** 등록해야 통과합니다.
2. **해시·난수 통계** — 해시 난수기 호출은 무조건 실패. ID 생성·게임 연출은 제외.
3. **통화 단위** — `won억()`은 억원 단위를 받습니다. `*1e8`을 곱해 넘기면 실패.
4. **게시글 XSS** — 사용자 글이 이스케이프 없이 HTML로 들어가는 지점.
5. **관리자 키 노출** — 쿼리스트링으로 키를 보내면 실패(서버 로그에 원문이 남음).
6. **관리자 엔드포인트 인증** — 관리자성 액션에 키 검증이 없으면 실패.
7. JS 문법 · 8. JSON-LD 파싱 · 9. 같은 이름 함수의 중복 정의(경고)

### `node tools/verify-render.js` — 전수 렌더 (수 분)

WebKit(Safari 엔진)으로 **선택 가능한 지자체 전부**의 상세페이지를 실제로 엽니다.
`차트 정상`과 `Chart.js CDN 장애` 두 시나리오를 모두 돌립니다.

각 지역마다: 예외 · `NaN`/`undefined`/`null` 노출 · 억↔조 단위 오용 ·
본문 길이 · 제목이 요청한 지역과 맞는지 · 가로스크롤.

> **표본 검사로는 못 잡습니다.** 2026-09-04에 전남광주통합특별시 소속 27곳과
> 인천 서해구의 상세페이지가 아예 뜨지 않고 있었는데, 강진군 한 곳만 열어 봤기
> 때문에 그때까지 아무도 몰랐습니다.

필요: `npx playwright install webkit`

## 자동 실행

## 검사기 자체를 시험하는 법

검사기가 실제로 잡는지 확인하려면, 과거 결함을 일부러 되돌려 넣고 돌려 봅니다.
2026-09-04 기준으로 아래 6종을 전부 실패로 잡는 것을 확인했습니다.

- `total * 0.55 / 0.25 / 0.62` (4단 자금흐름)
- `R.budget * .85 / .88 / .93` (5년 추이)
- `R.execRate * 0.22 / 0.47 / 0.74` (분기 집행률)
- `h32x()` 해시 난수기 호출
- `won억(R.execBase * 1e8)` (단위 오용)
- `'<div>' + it.content` (이스케이프 없는 게시글)
- admin.html 헤더 래퍼 제거 · api/chat.js 키 검증 제거
